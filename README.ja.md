# Canvas Kanban Sync

Obsidian Canvas上で2次元的に自由に発想を広げながら、着手日・完了日を自動で
記録するKanbanボードです。「詰んでいるのに、いつまでも終わらないタスク」を
一目で見つけられます。

[English](README.md) | 日本語

---

## これは何？

![カードを別グループへドラッグすると、Statusプロパティが自動的に同期される様子](assets/drag-and-drop-sync.gif)

*このGIFでは分かりやすさのため、カードをドロップしてからStatusプロパティが更新されるまでの待ち時間を短縮しています。実際にはもう少し時間がかかることがあります。*

Canvas上のグループ名(Todo / Doing / Done など、名前は自由に決められます)が、
そのままノートのStatusプロパティになります。カードをグループ間でドラッグする
だけで、ノート側のfrontmatterが自動的に更新されます。

## 開発の背景

これまでNotionとFigJamを、それぞれタスク管理に使ってきました。

- **Notion**: アジャイル的な考え方でタスクを管理し、着手日・完了日を記録して
  振り返っていました。ただしデータベース/リスト形式なので、思考を2次元的に
  自由に広げることができませんでした
- **FigJam**: カンバン形式でタスクを自由に配置できる、2次元的な自由度が
  気に入っていました。ただし追跡機能が無いため、「着手したのに詰んでいて、
  いつまでも終わらないタスク」がボード上に埋もれて気づけない、という問題が
  ありました

このプラグインは、両方の良いところを組み合わせたものです。Obsidian Canvas
という自由なキャンバス上でカンバン運用しながら、カードを動かすだけで着手日・
完了日が自動的に記録されます。特に「経過日数バッジ」は、着手してから止まって
いるタスクを一目で見つけるための機能です。

タスクの優先順位付けや管理そのものはこのプラグインの役割ではありません
(将来的にはAIに任せることを想定しています)。あくまで「気づくために必要な
データを、手間なく自動で残す」ことに徹しています。

## できること

- Canvas上のグループ移動だけで、ノートのStatusプロパティを自動更新
- グループ名は完全に自由（Todo/Doing/Doneに縛られない）
- 完了したカードだけをCanvasから片付けるArchive機能（手動 / 曜日指定の自動実行、
  自動実行はデフォルトOFF）
- 着手からの経過日数をカード上にバッジ表示
- 同期対象にするノートを判定するタグをカスタマイズ可能
- 自動更新される各プロパティ(Status/StartedAt/ModifiedAt/CompletedAt)の
  プロパティ名を変更可能。Status以外はOFFにもできる
- Canvasカードのプロパティは普段非表示。ⓘマークにカーソルを合わせた時だけ
  一時的に表示（クリックで固定表示も可能）

## インストール

コミュニティプラグインからインストールしてください。

1. 設定 → コミュニティプラグイン → 閲覧
2. 「Canvas Kanban Sync」を検索してインストール
3. 有効化する

## 実際に使う

コマンドパレット(Cmd/Ctrl+P)から**Create task canvas**を実行すると、Todo /
Doing / Doneの空のグループだけを持つCanvasが、指定したパス(デフォルトは
Vaultルート直下)に作成されます。あとはタスクノートにタグを付けてカードを
配置していくだけです。

## チュートリアルを試す

いきなり自分のVaultで運用を始める前に、コマンドパレットから
**チュートリアル用Canvasを作成（日本語）**を実行すると、実際に手を動かして
主要機能を確認できます。

- Vaultルートに`Canvas Kanban Sync チュートリアル`というフォルダが作成され、
  Canvas本体とサンプルノート6件がすべてその中にまとまります。ルート直下に
  他のファイルが増えることはありません
- フォルダの中だけで完結しているので、実際にカードをドラッグしたり、
  Archiveコマンドを試したりして自由に確認できます(自分の本番用Canvasの
  設定には一切影響しません)
- 不要になったら、このフォルダを削除するだけで、試した形跡を残さず
  リセットできます

![チュートリアル用Canvasを開いた直後の全体像（⓪の案内、①〜⑥のサンプルカードが並んだ状態）](assets/tutorial-overview.png)

## 使い方

対象のCanvas上でタスクノートのカードをグループ間で動かすと、frontmatterへ
以下のように反映されます（フィールド名は設定で変更可能）。

```yaml
---
tags:
  - task
Status: Doing
StartedAt: 2026-09-06 10:00
ModifiedAt: 2026-09-06 10:00
---
```

- `Status`: カードが今どのグループにあるかを表す。グループ名がそのまま入る
- `StartedAt`: 未着手（Statusが空）の状態から最初にどこかのグループへ配置
  された時刻。経過日数バッジの起点になる
- `ModifiedAt`: Statusが変わるたびに更新される時刻
- `CompletedAt`: 完了扱いのグループに入った時刻

![カードのタイトル脇に表示される経過日数バッジと、ⓘマークにカーソルを合わせてプロパティが一時的に開く様子](assets/elapsed-days-and-hover.gif)

## Archiveについて

完了したタスクのカードを、Canvasから取り除いて整理できます。ノート自体と
Statusプロパティは削除されず、Canvas上の配置だけが消えます。

- 手動: コマンドパレットから「Archive done tasks」を実行
- 自動: 設定画面で曜日を指定して毎週自動実行（デフォルトはOFF）

![Doneグループのカードが「Archive done tasks」実行後にCanvasから消える様子](assets/archive-done-tasks.gif)

## 設定

設定画面から、以下をカスタマイズできます。

| 設定項目 | 内容 |
|---|---|
| Target Canvas path | 同期対象にするCanvasファイル |
| Task tag | どのタグを持つノートを同期対象にするか |
| Group treated as Done | どのグループを「完了」として扱うか |
| Automatic Archive / Archive weekday | 週次自動Archiveの有効化と曜日 |
| Property used as Status / StartedAt / ModifiedAt / CompletedAt | 各プロパティ名（Status以外は空欄でOFFにできる） |

## 注意事項

Canvasカードのプロパティ表示の切り替えには、Obsidianの内部的なDOM構造を
利用しています。Obsidianのアップデートで見た目が崩れる可能性があります。
